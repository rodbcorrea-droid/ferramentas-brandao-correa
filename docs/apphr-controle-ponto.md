# AppHR — Controle de Ponto e RH
## URL: https://drogavanpopular.bitrix24.site/testes_jnbo/
## Título: "AppHR"

### Descrição:
Sistema de gestão de recursos humanos (RH) com controle de ponto, integrado com Bitrix24.

### Módulos:

#### 1. Ponto Rápido (Clock In/Out)
- Registro de entrada/saída em tempo real
- Cronômetro de horas trabalhadas (formato HH:MM:SS)
- Status de sincronização visível

#### 2. Controle de Ponto
- Histórico completo de registros
- Colunas: Data, Funcionário, Entrada, Saída, Total Hs, Atividades

#### 3. Lançamento de Faltas
- Registro de faltas por funcionário
- Campos: Data da Falta, Tipo, Motivo/Observação
- Histórico de faltas com ações

#### 4. Conta Corrente (Vales)
- Controle de adiantamentos/vales
- Vales ativos com: Data, Funcionário, Motivo, Valor Total, Saldo Devedor
- Ações por vale

#### 5. Relatórios e Exportação
- Tipos de relatório configuráveis
- Filtro por Mês/Ano
- Filtro por Funcionário (opcional)
- Exportação de dados

### Dados por funcionário (colunas principais):
- ID
- Nome
- Cargo
- Departamento
- Ações

### Notas:
- Integrado com Bitrix24 (drogavanpopular.bitrix24.site)
- Provavelmente usado para controle de funcionários do escritório ou de outro negócio
- Sistema SPA (Single Page Application)
- Interface em português
- Status "Sincronizado" indica integração em tempo real com Bitrix24 CRM

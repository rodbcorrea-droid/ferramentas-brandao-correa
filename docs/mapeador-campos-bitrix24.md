# Mapeador Pro Bitrix24 — Contatos
## URL: https://drogavanpopular.bitrix24.site/testes_rrip_jlcf/
## Título: "Mapeador Pro Bitrix24 - Contatos"

### Descrição:
Ferramenta utilitária para mapear campos e listas da entidade Contato no Bitrix24 CRM.

### Funcionalidade:
- Insere URL do Webhook de entrada Bitrix24 (com permissão de CRM)
- Mapeia campos da entidade Contato
- Lista: Nome do Campo, Código (ID Técnico), Tipo/Opções

### Uso:
- Ferramenta de desenvolvimento/debug para integradores
- Permite visualizar a estrutura de campos customizados do CRM
- Útil para configurar SPAs, dashboards e integrações

### Notas:
- Ferramenta auxiliar para desenvolvimento
- Usada por Rod para mapear campos antes de criar SPAs e dashboards
- Provavelmente usada para configurar o Dashboard Financeiro e AppHR
